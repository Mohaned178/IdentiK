# Identity is Organization-scoped; applications see Enrollments

One Identity per person per Organization; client Applications see only Enrollments (Identity × Application membership records), created silently at the Identity's first authentication through that Application — authenticating at a new Application *is* enrolling. Credentials attach to the Identity, never to an Application: one password per person per Organization. This delivers the cross-application SSO promise (sign in once, use every app in the Organization) while keeping Instance-global identity structurally impossible — a person may exist as unlinked Identities in multiple Organizations, and in hosted mode we can honestly tell one customer "your users are not also someone else's users." The dashboard's "users of Zotac" is formally Enrollments filtered to Zotac. Rejected: per-application identities (an IdP without shared identity is just a login API) and Instance-global identity (a tenancy violation).
