# Two identity populations: Administrators and End Users

Platform-side humans (Administrators logging into the dashboard) and application-side humans (End Users authenticating to Applications) are distinct entity types with separate credential stores, separate sign-in flows, and separate session types. An Administrator never "is" an End User and vice versa; the dashboard's user screens list only End Users. Administrators authenticate via a dedicated sign-in with no self-serve path (invitation only). This makes the administrative trust boundary structural: a compromised End-User session in any Application can never become a foothold toward tenant administration. Cost accepted: an Administrator needs a separate End-User Identity to dogfood a client application — that is what they would do anyway.
