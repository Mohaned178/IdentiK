# Management API exists from day one; dashboard is its first client

A single Management API is the platform's only programmatic surface, and the dashboard is its first client — the dashboard is itself a first-party Application of the Organization, so the platform grows no dashboard-only back doors. In this release the Management API is callable only by Administrator sessions. Programmatic access for client Application backends (e.g., auto-suspend on a fraud trigger) arrives together with the deferred machine-to-machine Application type, purely additively. Rejected: full client-backend management access now (it is M2M plus a delegation model plus "the Application did it" audit semantics — the deferred type smuggled in through the back door); dashboard-only with no API (the dashboard becomes a private API's accidental public shadow later).
